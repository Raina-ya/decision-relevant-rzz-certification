# LAKENS2018 reading note

Reading status: relevant sections read. Reviewed the equivalence-testing
framework, approaches to selecting the smallest effect size of interest,
confidence-interval/TOST decisions, power implications, examples, and
discussion.

- Question: How should equivalence bounds be chosen, tested, and reported when
  the scientific target is absence of a meaningful effect rather than exact
  equality?
- Design: two one-sided tests against a prespecified smallest effect size of
  interest; the confidence interval offers an equivalent visual decision in
  the standard cases treated.
- Outcomes: the analysis explicitly distinguishes statistical equivalence
  from insufficient data. Narrower meaningful-effect bounds demand larger
  samples.
- Error control: bounds and error rates must be chosen before observing the
  result; data-dependent bounds invalidate the advertised fixed error rates.
- Relation to Ch4: the downstream tolerance needs an external scientific
  justification and prospective freeze. The generic three-way intuition of
  practically negligible, meaningfully different, or unresolved is not by
  itself novel.
