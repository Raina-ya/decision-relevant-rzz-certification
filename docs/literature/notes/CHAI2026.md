# CHAI2026 reading note

Reading status: relevant sections read (arXiv HTML full text, 2026-11-27):
method, uncertainty treatment, hardware section, limitations.

- Question: estimate the signed per-cycle residual ZZ angle of a CZ-type gate,
  separated from target detuning, SPAM and contrast loss.
- Probe: repeated cycles with Pauli-block readout (IX, IY, ZX, ZY);
  control-conditioned branch coherences C+ and C-; nonlocal ZZ moves the two
  branch phase slopes oppositely, local target phase moves them together;
  echoed variant suppresses local terms; matrix-pencil estimator with DC-pole
  rejection for SPAM.
- Uncertainty: bootstrap standard deviation (B = 200); no hypothesis test; the
  authors state their feedback effect is not significant at the shot budget.
- Hardware: QuantumCTek gd_qc1, one pair, pulse-level access; CZ only, no
  fractional angles; no delay/reference circuits for frame detuning.
- Stated limitations: single damping rate; leakage beating; control ZI drift;
  one pair, one session; no multi-round convergence guarantee.
- Implications for Ch4:
  - The control-state-switching principle (opposite slopes for ZZ, common
    slope for local phase) is prior art. Ch4 Section 4 and L1/L2 must cite it
    and RUDINGER2025 and claim no novelty for the probe principle.
  - Remaining Ch4 differences: native fractional angle family on a
    non-pulse-level public cloud; delay-matched controls; finite-sample
    intervals; decision-induced tolerance; replication.
