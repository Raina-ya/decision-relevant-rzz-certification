# DENG2026 reading note

Reading status: relevant sections read (arXiv HTML full text, first 100k
characters, 2026-11-27): abstract, estimator construction, decision rule,
limitations.

- Question: does a multiqubit diagonal phase gate belong to its declared
  generalized-gate equivalence class?
- Probe: gate/reference Ramsey arms with equal-duration reference X/Y
  quadratures, interleaved; depths q in {1, 2, 4} where q = 1 anchors the
  logarithm branch; Walsh transform of the eigenphase map gives the diagonal
  error generator.
- Decision: pass / fail / unresolved under prespecified tolerance vectors and
  simultaneous confidence; model rejection (branch boundary, alias,
  depth-residual nonstationarity) is reported separately from equivalence.
- Guarantee: local-Gaussian union bound; the paper states its familywise error
  is asymptotic. No finite-sample guarantee and no minimax lower bound.
- Evidence: seeded simulations only; no hardware.
- Stated limitations: branch-local logarithm; diagonal model cannot represent
  off-diagonal error or leakage; quasistatic offsets are a floor; experimental
  validation open.
- Implications for Ch4:
  - C2 mechanics (three outcomes, prespecified tolerance, simultaneous
    confidence, separating model rejection from the verdict) are prior art and
    must be cited. OD11's separation is not new.
  - Remaining Ch4 differences: tolerance induced by a downstream decision
    functional rather than user-specified; strict finite-sample validity;
    a minimax-type lower bound for the decision projection; an off-diagonal
    (Z-conservation) diagnostic; native fractional RZZ hardware data.
