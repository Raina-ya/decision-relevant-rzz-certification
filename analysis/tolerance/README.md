# Tolerance analysis

Status: development only. No decision family, margin, seed, or tolerance region
is locked.

`src/decision.py` provides exact p=1 MaxCut expectations for 2-4 qubit graph
instances, two prespecified candidate parameter sets, and one M0 error triple
per edge. It defines the signed decision functional `gamma(e)` without assuming
that error is affine across angles.

The unlocked development family is generated by
`python -m analysis.tolerance.generate_development`. The 2-qubit one-edge
instance is the only hardware-primary member because the probe design covers
one physical pair. The 3- and 4-qubit paths are method extensions; they require
per-pair evidence before any hardware certification claim. All instances use
exactly two shared edge angles and a fixed seeded rejection rule for near-tied
ideal candidates. OD1/OD2 record the rationale and margin rule. This is
`[exact]` development evidence, not a protocol lock.

`regions.py` separates three evidence levels:

- exact statevector membership at a supplied error point;
- a globally valid conservative L1 inner ball and equal-width box;
- sampled-and-bisected radial crossings for diagnostics or plots only.

The numerical crossing is not used as a proof that an entire region is safe.
