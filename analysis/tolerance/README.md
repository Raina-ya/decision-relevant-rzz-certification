# Tolerance analysis

Status: development only. No decision family, margin, seed, or tolerance region
is locked.

`src/decision.py` provides exact p=1 MaxCut expectations for 2-4 qubit graph
instances, two prespecified candidate parameter sets, and one M0 error triple
per edge. It defines the signed decision functional `gamma(e)` without assuming
that error is affine across angles.

The unlocked development family is generated by
`python -m analysis.tolerance.generate_development`. It contains path graphs on
2-4 qubits, exactly two shared edge angles per instance, and a fixed seeded
rejection rule for near-tied ideal candidates. OD1/OD2 record the rationale and
margin rule. This is `[exact]` development evidence, not a protocol lock.
